# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

投递前必须核对**墨路冲洗口令**：印刷员生成当日口令，投递必须填写当日仍有效的口令；错令或隔日旧令一律退回。成功入队后该口令记为已用，不可再次使用；作废写入流水。观察账号能看口令与流水，但不能生成也不能作废。

```bash
cd projects/15-print-register-review

```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 进入「墨路冲洗口令」页生成今日口令；回到复核队列挂上该口令送一条，状态先是待处理，随后变成结论（青偏差 0.5 则套不准）。
3. 同一口令再投第二笔，接口退回“口令已使用”。
4. 错令、隔日旧令、已作废口令投递一律退回；作废后在作废记录与口令流水中可见。
5. checker 没有送复核、生成、作废按钮，但能看到有效口令、作废记录与流水。
